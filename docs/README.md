# 课程笔记与资料索引

本目录用于存放**跨周通用**的学习资料，与具体某周无关的内容放这里，避免每个 `weekNN` 目录里重复堆积。

| 文件 / 目录 | 说明 |
| :--- | :--- |
| `notes/` | 按知识点整理的课堂笔记（如 `01_变量与数据类型.md`） |
| `environment.md` | 本机环境安装与配置记录（建议自行新建） |
| `faq.md` | 踩坑合集：报错信息 + 解决办法（建议自行新建） |

## 记笔记的小建议

1. **一页一个知识点**，文件名用「序号_知识点.md」，序号决定阅读顺序。
2. 每条报错都记下三样东西：**原始报错文字**、**我的猜测**、**最终解决办法**。学期末复习时这是最有价值的资料。
3. 写"人话"：假设三个月后的自己什么都忘了，写给自己看。
