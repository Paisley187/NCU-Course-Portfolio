```text

├── README.md                 ← 你正在看的文件：仓库总说明 + 进度总览
```

## 四、每周实验标准流程（SOP）

1. **开始实验前**：`git pull` —— 先把云端最新内容同步到本地。
2. **实验过程中**：所有代码写进本周 `code/`，截图放进本周 `assets/`。
3. **写实验报告**：直接编辑本周的 `README.md`，把 `[待填写]` 替换成真实内容。
4. **提交作业**：

   ```bash
   git add .
   git commit -m "feat(week03): 完成第3周实验——循环结构"
   git push
   ```

5. **更新总进度**：回到本文件第三节，把对应周次状态改为 ✅。

### Commit 信息规范（推荐）

```text
feat(weekNN):  新增本周实验内容
fix(weekNN):   修复实验中的错误
docs(weekNN):  补充笔记或报告文字
chore:         仓库维护（如更新 .gitignore）
```
